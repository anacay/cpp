# Welcome discussion (pin in Governance)

**Title:** Welcome: how to comment, and what happens next

**Body:**

Welcome to the Capacity Planning Practice.

This is a request for comments: a draft shared on purpose, so the people who do the work can improve it. Everything starts from the seed paper, *The Coefficient Is an Agreement*, at https://cpp.anacay.org/paper/.

**How to comment**

1. On the site, select any sentence. A **Discuss this passage** button appears at the bottom of the screen. Or use **Discuss** at the end of any page.
2. You land here, with the passage quoted for you. Add your comment and press **Start discussion**.
3. Not sure where something goes? Post it in **Sections**. It can be moved later.

**Where to start:** the author's open questions, at https://cpp.anacay.org/open-questions/. Each one already has its own thread in Sections.

**What happens next:** the author reads every thread and replies. Others can join in. When a thread points to a change, it follows [How it grows](https://github.com/anacay/cpp/blob/main/HOW_IT_GROWS.md), and everyone who helped is credited by name in [CONTRIBUTORS.md](https://github.com/anacay/cpp/blob/main/CONTRIBUTORS.md).

**A good comment can be one sentence.** "This doesn't match what I've seen, because…" · "Here's a public source for this: …" · "My team does this differently: …"

**Please don't share** anything confidential to an employer, client or vendor, or real internal numbers. Invent illustrative ones and label them. The [Code of Conduct](https://github.com/anacay/cpp/blob/main/CODE_OF_CONDUCT.md) applies here.

**No GitHub account?** Anyone can read here. To comment without an account, write to cpp@anacay.org.
